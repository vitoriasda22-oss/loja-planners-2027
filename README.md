# Loja de planners 2027 — versão inicial

Site estático em português brasileiro para apresentação de Planner de Metas 2027, Planilha Financeira e Mapa dos Sonhos.

## Publicação com GitHub Pages
1. No GitHub, crie um repositório público (por exemplo `loja-planners-2027`).
2. Adicione `index.html` na raiz do repositório (e opcionalmente este README).
3. Entre em **Settings → Pages** e escolha **Deploy from a branch**, `main` e `/ (root)`.
4. Aguarde a publicação e abra o endereço mostrado em Pages.

## Antes de vender
- Substitua nome e identidade visual provisórios.
- Finalize os materiais digitais e revise conteúdo e funcionalidades.
- Defina preços, suporte, termos, privacidade e política de entrega/reembolso aplicáveis.
- Integre checkout seguro e fluxo de liberação/entrega dos arquivos.

**Importante:** botões de compra intencionalmente desabilitados. Não existe cobrança nem entrega automática nesta prévia.
